## 🔑 Key Decisions (From Our Conversation)

### Technology Stack:
- **React + TypeScript + Vite** - Your preference, professional setup
- **OpenRouter** - Your existing account, access to 100+ models
- **User API Keys** - Privacy-friendly, no backend costs
- **Manifest V3** - Latest Chrome extension standard

### AI Provider:
- **OpenRouter** primary (you have account)
- **HuggingFace** future option
- GPT-4, Claude, Llama models available
- Free models available (Llama 3 70B)

### Architecture:
- **Content Script** - Detects ChatGPT input, injects results
- **Background Worker** - Handles API calls (avoids CORS)
- **Popup UI** - Settings, API key management
- **Message Passing** - Chrome runtime communication

### Prompt Engineering:
- Uses expert system prompt (inspired by generateprompt.ai)
- Teaches AI to add clarity, context, structure
- Includes examples for better results

## 🎯 Your Goal (From Our Discussion)

**What you wanted:**
> "I want to build an extension for Chrome that will format my input text as a normal prompt when I'm typing in ChatGPT input or something else"

**What we designed:**
1. User types rough prompt: "write about dogs"
2. Presses Ctrl+Shift+F
3. Extension sends to AI (OpenRouter)
4. AI formats it professionally
5. Extension injects result back
6. User gets better ChatGPT responses

**Phase 1 (MVP):** ChatGPT only, basic formatting  
**Phase 2-5:** More sites, templates, advanced features (see ROADMAP.md)

## 📞 Getting Help

### If You're Stuck:

1. **Check the docs** - Answer is probably in:
   - GETTING_STARTED.md (troubleshooting section)
   - ARCHITECTURE.md (how it works)
   - API_INTEGRATION.md (OpenRouter issues)

2. **Check the logs** - Use browser DevTools:
   - Content script: F12 on ChatGPT page
   - Background: chrome://extensions/ → Inspect
   - Popup: Right-click icon → Inspect popup

3. **Common issues:**
   - "API key not found" → Check popup settings
   - "Input field not found" → Update selectors in content.ts
   - Extension not loading → Rebuild and reload extension

4. **External resources:**
   - Chrome Extension docs
   - OpenRouter docs
   - Stack Overflow
   - Chrome extension communities
